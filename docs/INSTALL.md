# 安装与更新 · 桥 · Session Bridge v0.4.2

本页面向**普通用户**。看完就能装好、能用、能更新。

---

## 一、先说结论

| 你的情况 | 用哪种方式 |
|---|---|
| 现在就想用最新版 | **方式一：GitHub Releases 下载**（最新 v0.4.2） |
| 想省心、自动更新 | **方式二：Edge 商店**（v0.4.2 已提交、审核中；通过前商店仍是 v0.4.1） |

无论哪种，**不需要** npm、Python、编译，也不需要 DeepSeek API Key —— 默认的「完整原文」迁移在本机完成，不联网。

---

## 二、方式一：从 GitHub Releases 下载安装（现在可用）

1. 打开本仓库的 **Releases** 页面：
   `https://github.com/kiloeee/bridge-session-bridge/releases`
2. 在 **Assets** 下面下载 **`bridge-v0.4.2-edge.zip`**。
   - **不要**下载 GitHub 自动生成的「Source code (zip)」。那个是源码，不能安装。
3. 把 ZIP **解压到一个你会长期保留的固定文件夹**。
   - 例如 `D:\bridge-v0.4.2\`。
   - 解压后该文件夹里应能直接看到 `manifest.json`。
4. 在 Edge 地址栏输入 `edge://extensions` 并回车。
5. 打开左下角的 **开发人员模式**。
6. 点 **加载解压缩的扩展**，选择第 3 步那个**含 `manifest.json` 的文件夹**。
7. 打开 `https://chat.deepseek.com/`，点浏览器工具栏里的扩展图标，打开侧边栏。

完成后扩展卡片上应显示 **桥 · Session Bridge**，版本 **0.4.2**。

### 核对下载是否完整

`bridge-v0.4.2-edge.zip` 的 SHA-256：

```
489008dae40751c00ee0f59176b7078e80ad5388418cf7dacdf65426c50c89d0
```

Windows 上核对方法（在存放 ZIP 的文件夹打开 PowerShell）：

```powershell
Get-FileHash .\bridge-v0.4.2-edge.zip -Algorithm SHA256
```

输出与上面一致即可。

### 常见误解

- **ZIP 不能双击安装。** Edge 要的是「解压后的文件夹」，不是 ZIP 文件。
- 不要只在 ZIP 里点「全部解压缩」到一个临时目录 —— 那个目录以后可能被系统清理，扩展就会失效。请解压到固定文件夹。

## 四、更新（重要，请读完）

三条渠道的更新行为**不一样**：

| 安装方式 | 如何更新 | 是否自动 |
|---|---|---|
| **Edge 商店** | Edge 自动更新 | ✅ 自动 |
| **GitHub ZIP / 解压版** | 见下方手动步骤 | ❌ 手动 |
| 自托管 CRX | v0.4 不实现，仅记录为将来可行性 | — |

### GitHub 解压版手动更新步骤

1. 下载新版 ZIP 并解压。
2. 用新文件**覆盖同一个文件夹**里的旧文件。
3. 到 `edge://extensions`，在扩展卡片上点 **重新加载**。
4. 如果侧边栏或页面脚本像是旧版本，**刷新一下 DeepSeek 页面**。

**从 GitHub 装的解压版不会自己下载新版本。** 请自行留意本仓库的 Releases。

### 换文件夹、装两种版本会怎样

扩展 ID 决定了本地存档（IndexedDB / 设置）存在哪。

- **同一个文件夹里替换文件** → 扩展 ID 不变 → **原有存档与设置保留**。
- **换到另一个文件夹加载** → 扩展 ID 会变化 → 相当于一个**全新的扩展**，看不到旧文件夹那份本地存档。
- **商店版和解压版同时安装** → 两者扩展 ID 不同，存档互相隔离；但它们会同时作用在同一个 DeepSeek 页面上，可能互相干扰。**建议只保留一个。**

> 如果你已经装了 v0.3 的商店版，**不要以为 v0.4 解压版是它的原地升级** —— 两者扩展 ID 不同，是彼此独立的两个扩展。

### 会不会覆盖或删除你已有的聊天存档？

不会。安装、更新、重新加载都不会删掉你本地已有的存档。扩展也从不主动上传存档。

## 五、卸载

`edge://extensions` → 找到 **桥 · Session Bridge** → **移除**。

本地存档随扩展 ID 一起被浏览器管理；如需保留，请先用扩展「设置 → 本地数据 → 备份全部」导出。

---

## 六、出问题时

- 侧边栏打不开 / 页面脚本没反应：先**刷新 DeepSeek 页面**，再重新打开侧边栏。
- 迁移失败：完成页会说明原因，并提供**用户自己修改后重发**的入口；原始错误在「设置 → 开发诊断」。
- 反馈请附**不含聊天正文**的诊断报告（「复制测试报告」只含数量、字符数与状态）。见 [`../SECURITY.md`](../SECURITY.md)。
